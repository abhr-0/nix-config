# AGENTS.md

Flake-based NixOS + Home Manager config for hosts `earth` and `pluto` (x86_64-linux).
`README.md` has the host/directory overview. Modules are loaded with `import-tree`;
there is no central import list.

## Commands

| Purpose | Command |
| --- | --- |
| CI gate (hosts + nixvim + pre-commit) | `nix flake check` |
| Cheap eval of one host | `nix eval --raw .#nixosConfigurations.earth.config.system.build.toplevel.drvPath` |
| Build host without switching | `nixos-rebuild build --flake .#earth` |
| Apply host | `sudo nixos-rebuild switch --flake .#earth` (or `nh os switch`; `nh` is preconfigured to this repo) |
| Build VM variant | `nixos-rebuild build-vm --flake .#earth` (or `nh os build-vm`) |
| Run nixvim config | `nix run .#neovim` |
| Check nixvim only | `nix build .#checks.x86_64-linux.neovim` |
| Dev shell (sops, age, nix-init, nurl, nix-update, pre-commit) | `nix develop` (or `direnv allow`) |
| Format / lint | `nix fmt`; `pre-commit run --all-files` |

There is no separate test suite; `nix flake check` is the verification step.
Home Manager is a NixOS module here, so `home-manager switch` does not apply this
config; rebuild the host instead.

## Module layout

- `flake/*.nix` are flake-parts modules. `flake/nixos.nix` scans `hosts/` and creates
  `nixosConfigurations.<dirname>` from `hosts/<dirname>/configuration.nix`; a new host
  directory is enough.
- `nixosModules/**` is auto-imported into every host. `common/` is unconditional;
  `features/*.nix` expose `systemSettings.<name>.enable` (or `.bootloader`) that each
  host toggles in `hosts/<host>/configuration.nix`.
- `home-manager/abhro/*.nix` is auto-imported as part of the NixOS HM module
  (`useGlobalPkgs = true`). Use the passed `pkgs`; don't instantiate another nixpkgs.
- `import-tree` ignores any path containing a `_`-prefixed component. Disabled modules
  are deliberately kept as `_home-manager.nix`, `_sops.nix`, `_winrdp.nix`; rename to
  activate them.
- `nixvim/**` is standalone: `flake/nixvim.nix` evaluates it with `evalNixvim` against
  its own `nixpkgs-unstable`, independent of the host's nixpkgs, and exposes it as
  `packages.neovim` (`nix run .#neovim`). `flake/pkgs.nix` also exposes all
  `perSystem` packages as `localPkgs`, so HM installs that same build via
  `localPkgs.neovim` in `home-manager/abhro/home.nix` (package and `$EDITOR`).
  Nixvim breakage therefore still surfaces in `nix flake check` and host rebuilds.
  Put language/filetype config in `nixvim/langs/`, plugin config in
  `nixvim/plugins/`.

## Packages and overlays

- To add a local package, create `pkgs/<name>.nix` as a `callPackage`-style function.
  `flake/pkgs.nix` auto-loads every file in `pkgs/` as `localPkgs.<name>` and
  `packages.<system>.<name>`. Reference it as `localPkgs.foo` in modules.
- The devshell provides package-maintenance tools: `nix-init` scaffolds a derivation
  from a source URL, `nurl` generates fetcher calls with hashes, and `nix-update`
  bumps the version/hash of an existing package.
- `unstablePkgs` is a separate nixpkgs-unstable instance exposed by the same overlay.
- nixvim also follows `nixpkgs-unstable`. If nixvim fails to build, remove the unstable
  follow in both `flake.nix` and `flake/nixvim.nix` (per the warning in those files).

## Repo-specific gotchas

- `hosts/*/hardware-configuration.nix` is generated by `nixos-generate-config`;
  pre-commit and statix ignore it. Don't hand-edit it.
- `.pre-commit-config.yaml` is generated by git-hooks.nix and gitignored. Edit hooks in
  `flake/shell.nix`; never edit the generated file.
- Secrets use sops-nix + age; `secrets/*.yaml` are encrypted. `secrets/host.yaml` is the
  default, and `flake/nixos.nix` wires `secrets/<host>.yaml` into `usbguard_rules_file`.
  Add host keys/rules in `.sops.yaml` when adding a host or secret. `age.sshKeyPaths = []`
  and `generateKey = false`, so sops-nix will not import or generate host keys.
- NixOS `system.stateVersion` is `23.05` and HM is `24.11`; don't bump without intent.
- `nixpkgs` is pinned to 26.05 while nixvim and selected packages use unstable; don't
  assume a package version matches the system nixpkgs.
